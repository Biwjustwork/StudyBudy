# Auth Service

โครงเริ่มต้นของบริการยืนยันตัวตนสำหรับ Study Buddy

## เริ่มใช้งานในเครื่อง

1. ติดตั้ง Node.js และ npm
2. เปิด terminal ในโฟลเดอร์ `services/auth-service`
3. ติดตั้ง dependencies ด้วย `npm install`
4. คัดลอก `.env.example` เป็น `.env` แล้วเปลี่ยน `AUTH_TOKEN_SECRET` เป็นค่าสุ่มเฉพาะเครื่อง ความยาวอย่างน้อย 32 ตัวอักษร
5. เริ่มบริการด้วย `npm run dev` หรือ `npm start`
6. เปิด `http://localhost:3001/health` ควรได้รับ JSON ที่มี `"status":"ok"`

ห้าม commit ไฟล์ `.env` หรือ secret จริงขึ้น GitHub

## ตรวจสอบข้อมูลสมัครสมาชิก

มีฟังก์ชันพื้นฐานสำหรับตรวจข้อมูลที่จะใช้ตอนสมัครสมาชิก:

- อีเมลต้องมีรูปแบบพื้นฐานที่ถูกต้อง
- รหัสผ่านต้องยาวอย่างน้อย 8 ตัว มีตัวพิมพ์ใหญ่ และมีเครื่องหมายหรือสัญลักษณ์ (ช่องว่างไม่นับเป็นสัญลักษณ์)
- ชื่อต้องมีข้อความหลังตัดช่องว่างหัวท้าย

รัน unit tests ด้วยคำสั่ง `npm test` จากโฟลเดอร์ `services/auth-service`

## Environment variables

| ตัวแปร | จำเป็น | ความหมาย |
| --- | --- | --- |
| `PORT` | ไม่ (ค่าเริ่มต้น `3001`) | port ที่ Auth Service ใช้รับ request |
| `AUTH_TOKEN_SECRET` | ใช่ | secret สำหรับใช้กับ JWT ในขั้นถัดไป |
| `JWT_EXPIRES_IN` | ไม่ (ค่าเริ่มต้น `1h`) | อายุ token ที่จะใช้ในขั้นถัดไป |

ขณะนี้มีเพียง `GET /health` สำหรับตรวจว่า service เปิดอยู่ และมีฟังก์ชันตรวจข้อมูลพื้นฐาน ยังไม่มี `POST /api/register`, `POST /api/login` หรือการจัดเก็บบัญชีผู้ใช้
