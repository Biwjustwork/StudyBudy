# Study Buddy Frontend

พื้นที่สำหรับ frontend ใหม่ของ Study Buddy

Frontend จะเรียก API ผ่าน port ที่เปิดจากเครื่อง host:

- Auth: `http://localhost:3001`
- Profile: `http://localhost:3002`
- Group: `http://localhost:3003`
- Membership: `http://localhost:3004`
- Notification: `http://localhost:3005`

ยังไม่มี Dockerfile จนกว่าจะเลือก frontend stack และรูปแบบ build/deploy ร่วมกัน
